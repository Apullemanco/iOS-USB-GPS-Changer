# Cómo contribuir

Las mejoras, correcciones de errores y nuevas funciones son bienvenidas.

## Flujo de trabajo
1. Haz un **Fork** de este repositorio.
2. Crea una rama para tu cambio (`git checkout -b feature/nueva-funcion`).
3. Prueba tus cambios ejecutando `py GPS_App.py` en Windows con un dispositivo iOS 17+ conectado por USB.
4. Haz **Commit** de tus cambios y abre un **Pull Request** describiendo qué agregaste o corregiste.

## Ideas para colaborar
* Búsqueda de direcciones o coordenadas por texto en el mapa.
* Rutas automáticas entre dos puntos con velocidad ajustable.
* Soporte para guardar ubicaciones favoritas.
